Политика конфиденциальности BOT | ShannY

Последнее обновление: 19 ноября 2026 года

Эта политика описывает, какие данные обрабатывает Discord-приложение BOT | ShannY («Бот»), для каких целей и как связаться с оператором. Она составлена по функциям и структуре предоставленного исходного кода. Фактическая обработка также зависит от конфигурации Бота, Discord-сервера и сторонних сервисов.

1. Какие данные обрабатываются

  • Данные Discord-взаимодействий. Когда пользователь вызывает команду, нажимает кнопку или отправляет форму, Discord передаёт Боту необходимые для выполнения действия сведения, например Discord ID пользователя, отображаемое имя, ID сервера и канала, а также данные конкретной команды или взаимодействия.
  • Идеи для видео. При использовании /idea Бот получает заголовок и необязательное описание идеи, отображаемое имя, аватар и Discord ID автора. Бот публикует карточку идеи в настроенном канале Discord. Данные идеи хранятся в сообщении Discord, а не в таблицах локальной SQLite-базы, предусмотренных исходным кодом.
  • Роли и серверные действия. При использовании панели ролей Бот обрабатывает ID участника и роли, необходимые для добавления или снятия роли. Команды модерации используют сведения о канале, сообщениях и участниках, необходимые для выполнения действия.
  • Данные YouTube. Для уведомлений Бот получает и обрабатывает общедоступные сведения о настроенных YouTube-каналах и публикациях, например идентификаторы видео и каналов, названия, ссылки, изображения и время публикации. В SQLite сохраняются идентификаторы уже обработанных и ожидающих публикаций, сведения о настроенных каналах и техническое состояние проверки.
  • Данные Twitch. Для проверки настроенных эфиров Бот обращается к Twitch API и обрабатывает общедоступные сведения о стримерах и трансляциях, например логин, название эфира, игру, ID трансляции и связанные ID Discord-сообщений и каналов. В SQLite сохраняется состояние уведомлений об эфирах.
  • Технические журналы. Бот записывает технические события и ошибки в локальные файлы журналов. Журналы могут содержать время события, название компонента и техническое описание ошибки. В коде настроена ротация журналов: текущий файл до 2 МБ и до трёх резервных файлов.

2. Для чего используются данные

Данные используются для выполнения команд и функций Бота: публикации идей, выдачи ролей, приветствий, модерации, показа ссылок и последнего видео, отправки уведомлений о YouTube-публикациях и Twitch-эфирах, обновления сообщений об эфирах, а также диагностики ошибок и поддержания работы Бота.

3. Локальное хранение и сроки

Исходный код использует локальную SQLite-базу для состояния YouTube и Twitch и технических значений. База не предназначена для хранения истории личных сообщений или постоянных профилей участников. Временное ограничение частоты отправки идей хранится в оперативной памяти до перезапуска Бота. Технические журналы ротируются по размеру; отдельный календарный срок хранения в коде не задан. Сообщения с идеями и другие публикации в каналах Discord хранятся на стороне Discord в соответствии с правилами и настройками Discord-сервера.

4. Передача сторонним сервисам

Бот взаимодействует с Discord для обработки команд и отправки сообщений. Для функций уведомлений он обращается к YouTube/Google и Twitch. Эти платформы могут получать технические запросы и обрабатывать данные согласно собственным политикам конфиденциальности. Бот не продаёт пользовательские данные и не использует их для рекламного профилирования.

5. Сообщения и приватность

В предоставленном исходном коде не обнаружен обработчик, который собирает и сохраняет содержание всех обычных сообщений сервера или личных сообщений. Однако команды модерации и функции вебхуков могут работать с сообщениями, которые пользователь или администратор явно выбрал для обработки.

6. Безопасность

Доступ к локальным файлам Бота, базе данных, журналам и ключам API должен быть ограничен оператором. Не публикуйте токены и ключи доступа. Несмотря на разумные меры защиты, абсолютную безопасность передачи и хранения данных гарантировать нельзя.

7. Запросы и удаление данных

По вопросам обработки данных, исправления или удаления сведений, которые оператор может контролировать, напишите на адрес ниже. Укажите Discord ID и опишите запрос; не отправляйте пароль, токен бота или другие секретные ключи. Контент, уже опубликованный в Discord, может требовать отдельного удаления через Discord или администратора сервера. Оператор не может удалить данные, которые контролируются непосредственно Discord, YouTube или Twitch.

8. Изменения политики

Политика может обновляться при изменении функций или способов обработки данных. Актуальная версия размещается на этой странице с датой последнего обновления.
