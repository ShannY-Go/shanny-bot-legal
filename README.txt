BOT | ShannY — документы для публикации

Файлы:
- index.html — главная страница со ссылками на документы
- terms.html — условия использования
- privacy.html — политика конфиденциальности

Перед публикацией:
1. Проверьте, что описание соответствует реально включённым функциям и настройкам бота.
2. Убедитесь, что адрес shanny.games.yt@gmail.com доступен для обращений.
3. Опубликуйте все три файла в корне публичного GitHub-репозитория.
4. В GitHub откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. После публикации откройте выданный GitHub Pages URL и проверьте, что index.html, terms.html и privacy.html доступны без входа в GitHub.
6. В Discord Developer Portal → General Information укажите полные публичные URL страниц terms.html и privacy.html в соответствующих полях.

Важно: это шаблоны документов, а не юридическое заключение. Проверьте их с учётом своей юрисдикции, фактической конфигурации и того, кто юридически является оператором приложения. Не публикуйте .env, токены, базу данных или логи вместе с этими страницами.
